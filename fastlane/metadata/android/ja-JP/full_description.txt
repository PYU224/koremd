これＭＤ（マジ）？は、Ionic と Vue 3 で構築されたシンプルで洗練された Markdown エディタです。

アプリ名には複数の意味が込められています：
- 「これＭＤ（マジ）？」 = 「これは Markdown？」の意味合い
- MD は モルドバ（Moldova） 🇲🇩 をも表しており、このプロジェクトはモルドバの方々とそこに住むウクライナ難民の方々を支援しています

機能：

• シンプルでクリーンなデザイン — ミニマルで集中できるインターフェース  
• Markdown エディタ — 装飾文字ツールバー付きリアルタイム編集  
• ライブプレビュー — 編集モードとプレビューモードの切り替え  
• クロスプラットフォーム — iOS、Android、Web、デスクトップ対応  
• 多言語対応 — 日本語と英語をサポート  
• カスタマイズ可能 — フォントサイズとフォントファミリーを調整可能  
• インポート／エクスポート — 簡単なファイル管理  
• ローカルストレージ — データはすべてデバイス内に保存  
• Wi-Fi Direct を使った高速ファイル転送（インターネット不要）  
• モルドバ支援 — モルドバ国旗の色をモチーフにしたデザイン

モルドバ支援について 🇲🇩

このプロジェクトはモルドバの方々とその地域のウクライナ難民支援を目的としています。  
アプリのデザインにはモルドバ国旗の色（青、赤、黄）が取り入れられています。

プライバシーとセキュリティ：

• すべてのファイルはデバイス内にローカル保存されます  
• インターネット接続は不要です  
• データ収集は行いません  
• トラッキングはありません  
• オープンソースで透明性があります
