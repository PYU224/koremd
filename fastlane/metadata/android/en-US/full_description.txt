KoreMD is a simple, elegant Markdown editor built with Ionic and Vue 3.

The name plays on multiple meanings:
- "Kore MD" = "Is this Markdown?"
- MD also represents Moldova 🇲🇩 — this project supports Moldovan people and Ukrainian refugees there.

Features:

• Simple & Clean Design — minimal, distraction-free interface  
• Markdown Editor — real-time editing with syntax toolbar  
• Live Preview — switch between edit and preview modes  
• Cross-Platform — works on iOS, Android, Web, and Desktop  
• Multi-language — Japanese and English support  
• Customizable — adjust font size and font family  
• Import/Export — easy file management  
• Local Storage — your data stays on your device  
• Fast file transfer via Wi-Fi Direct (no internet required)  
• Moldova support — design inspired by Moldovan flag colors

About Moldova Support 🇲🇩

This project is designed to support Moldovan people and the Ukrainian refugees living there.  
The app's design incorporates the color scheme of the Moldovan flag (blue, red, and yellow).

Privacy & Security:

• All files are stored locally on your device  
• No internet connection required  
• No data collection  
• No tracking  
• Open source and transparent
